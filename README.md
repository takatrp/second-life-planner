# セカンドライフ逆算プランナー

自営業者・会社経営者向けに、老後のありたい姿から必要資金を逆算し、個人資産・公的年金・年金保険・退職金準備を同じ画面で確認する静的ツールです。

## 使い方

`index.html` をブラウザで開くと利用できます。入力内容はブラウザのローカル保存に対応しています。保存・計画JSON出力・計画JSON読込は別の操作です。入力しただけでは自動保存されません。

## 面談の流れ

1. 基本入力: 原則12項目。配偶者なしでは配偶者入力を隠しますが保存済みの値は保持します。
2. 面談結果: 初回不足年、引退時の追加必要資金、残高グラフ、生活費・積立・引退年齢の独立した比較。法人原資は別枠です。
3. 詳細・根拠: 支出内訳、介護、年金開始・金額区分、その他収入、利回り、法人準備・税務参考、資料と確認日。全て初期状態では折り畳みます。

生活費は「合計入力」か「内訳を合算」の片方だけを計算に使います。合計には住居・医療・趣味を含め、介護と一時支出は別枠です。使わない側の値も保存し、切替前に両方の合計を表示します。以前の計画は内訳モードで読み込み、金額を変更しません。

「面談用に印刷」は主要な条件・リスクを含む短いサマリーを出します。長い面談メモ等はページが増えることがあります。全文は詳細のテキスト・JSON出力を利用してください。入力エラーや旧サマリー参照中は前の試算を消し、印刷にも持ち越しません。

## 計算規則

- 単位は内部・入力とも万円。表示の必要額は万円単位で切り上げ、計算には丸め前の数値を使用します。
- 計画期間は `[引退年齢, 計画終了年齢)`。65歳から85歳になるまでなら20年です。
- 引退時の一時支出を先に控除し、各年の年初残高にその年の収入を加え、支出を引き、その残額に年率の運用益を反映します。年内の細かな入出金時期は反映しません。
- 年ごとの黒字は翌年に繰り越します。必要資金は全期間の収支後・年末残高が負にならない最小の引退時資金を二分探索（隣接する浮動小数点値まで精密化し、演算の機械精度に由来する残差だけを処理）で求めます。
- 不足判定には0.000001万円の数値許容差を使います。必要額の探索・表示ではこの許容差を差し引かず、本当に追加資金が不要な場合だけ0とします。
- 現在価格を選んだ支出は現在から引退まで、退職時点価格なら引退後からインフレ率を反映します。年金・年金保険・仕事収入・その他収入は入力した名目額を固定し、物価連動は仮定しません。
- 年金保険の期間は0以上の整数年で入力します。小数年は計上せず入力エラーにします。
- 年金は本人・配偶者それぞれの年齢と受給開始年齢で判定します。手取り見込の入力を基本とし、額面入力時だけ明示した手取り仮定率を適用します。繰上げ・繰下げの法定調整額は自動計算しません。
- 介護費は対象者の開始年齢から月単位で各年へ配分します。計画期間外分は必要資金に含めず別表示します。
- 世帯計画に含める予定退職金は、支払われた場合の手取り額です。法人の確認済み支払可能額は独立した額面指標であり、予測した内部留保・保険額を自動的に確認済み原資とは扱いません。

## 保存と移行

保存形式は `version: 2` のJSONです。旧 `second-life-planner-state-v1` は読み込み時に移行しますが、旧localStorageの原本を削除しません。新形式の `legacyOriginal` にも旧JSON全文を保持します。旧サマリーJSONは元の入力項目を含まないため、原文だけを参照表示し、数値試算は停止します。「新規入力で試算を始める」を押してから金額を再入力してください。移行後の介護開始年齢や配偶者年金開始年齢などは仮定扱いです。復元には「計画を読込」で元のJSONを選ぶか、ブラウザ開発者ツールで旧localStorageの内容を参照してください。読込に失敗した場合は現計画を変更しません。v2の数値・必須項目・金額区分・根拠記録の型を読込前に検証し、欠けた金額を初期値で埋めません。

## テスト

`npm run test` で数値・判定・移行の回帰テスト、`npm run build` でJavaScriptの構文確認を実行します。ブラウザ操作・印刷プレビューは別途確認が必要です。

## 主な確認項目

- 現役から引退、平均余命までの期間
- 老後の基本生活費、医療、趣味、家族支援、介護予備費
- 公的年金、年金保険、退職後収入、不動産・配当等
- 個人資産形成と法人側の退職金原資
- 必要退職金と今からの追加準備額
